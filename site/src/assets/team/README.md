# Team photos

Drop photos into the folder named after a person (e.g. `nikhil-kumar/`).

- Any of .jpg, .jpeg, .png, .webp or .avif. Any size: the site resizes and compresses them.
- Files are shown in alphabetical order, and the first one is the cover. Name them `1.jpg`, `2.jpg`, … to control the order.
- One photo shows as a single print; two or more make a stack you can click through (the first three are used).
- Portrait (4:5) crops best. Faces near the top third survive the crop.

New person? Add them to `src/data/team.ts` and create a folder with the same `id`.
